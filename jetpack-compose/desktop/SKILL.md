# Jetpack Compose Desktop Features

## Description
This skill provides structured workflows for adding desktop-class features to Android apps built with Jetpack Compose. To keep instructions focused and token-efficient, the guidance is broken down by specific feature capabilities.

## Step 1: Identify the required desktop feature
Look at the user's prompt, requirements, or uploaded files to determine which desktop feature needs to be implemented.

## Step 2: Run feature-specific processing
Based on the feature identified, read the corresponding reference file and follow its instructions:

* **Keyboard Shortcuts** -> read `references/keyboard_shortcuts.md`
* **Tooltips** -> read `references/tooltips.md`
* **Custom Cursors** -> read `references/custom_cursors.md`
* **Desktop Windowing** -> read `references/desktop_windowing.md`

*(Future capabilities like drag and drop, or handoff will be added here as new branches.)*
